Beta 2 adds sequential programming with adjustable command cards.

### New

- **Program with cards** tab: command palette, drag-and-drop ordering, Move up/down, Duplicate and Remove.
- Editable parameters on selected cards: relative height/distance (cm), turn angle (degrees), speed (cm/s), and wait duration (seconds).
- Takeoff, land, six movement directions, clockwise/counterclockwise turns, four flip directions, speed, and wait/hover cards.
- Save/open portable JSON programs, a preloaded example, and first-flight/square lesson files in the repository.
- Runs highlight the active card, mark completed cards, and show progress. The runner waits for each acknowledgement before proceeding.
- Simulator position, height, heading and flip updates make parameter changes observable without a drone.
- Program state and parameters are included in persistent logs and support bundles.

### Execution behavior

Start with Take off and finish with Land. Manual controls are disabled during a run. **Stop & land**, global Land, or Space during a program discards the remaining cards and requests landing.
Errors, timeouts, stale telemetry, operator loss, and critically low battery stop execution. No uncertain movement is automatically retried. Flip cards require at least 50% battery.

### Downloads

Extract the full Windows ZIP or Linux tar.gz and keep the executable with `_internal`. No separate Python installation is required. Starts in simulator mode; choose **Program with cards** to try the editor. Linux targets Ubuntu 24.04 x86-64. Windows builds remain unsigned.

The expanded automated suite has 65 tests, and release CI runs it plus packaged diagnostics and a rendered card-editor check on Windows and Linux before publishing.

**Real-drone validation remains pending.** This implements the basic single-drone SDK programming commands, not EDU mission pads, swarms, the flight app's proprietary modes, loops, or conditions.
