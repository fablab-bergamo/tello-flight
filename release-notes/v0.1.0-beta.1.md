First beta of Tello Flight: a local Windows/Linux desktop console for the Ryze Tello.

### Included

- Camera-centered Qt interface inspired by the official Tello app, with Mode 2 joysticks and keyboard controls.
- Built-in simulator: try takeoff, manual controls, landing, and signal-loss diagnostics without a drone.
- Direct UDP SDK command handling, telemetry, input expiry, and disconnect watchdogs.
- H.264 camera receiver and preview snapshots.
- Persistent rotating JSONL logs and a **Save diagnostics** ZIP export for troubleshooting.
- Read-only command-line diagnostics using `TelloFlight --diagnose`.

### Downloads and installation

- **Windows x86-64:** download `TelloFlight-windows-x64.zip`, extract the entire archive, then run `TelloFlight/TelloFlight.exe`.
- **Linux x86-64:** download `TelloFlight-linux-x64.tar.gz`, extract it, then run `./TelloFlight/TelloFlight`. The initial target is Ubuntu 24.04 with a desktop session.
- Keep the executable and its `_internal` directory together. No separate Python installation is required.
- Compare the download's SHA-256 digest with `SHA256SUMS.txt`.

The application starts in simulator mode. Choose **Session settings → Live Tello** after connecting your computer to the drone Wi-Fi.

### Validation and beta limitations

- The automated suite has 18 tests covering the control engine, local UDP transport, generated H.264 decoding, diagnostics, CLI, and Qt simulator interface.
- Release CI must pass the tests and packaged runtime diagnostics on both Windows and Linux before publishing these assets.
- **No physical Tello has been available for validation.** Simulator tests do not verify real flight safety, Wi-Fi behavior, or camera latency. Start hardware evaluation with read-only diagnostics and grounded video.
- Windows packages are unsigned. Linux distributions other than the stated baseline have not been validated.
- Recording, mission pads, swarms, and autonomous flight sequences are not included.

For bug reports, describe what you expected and what happened, note simulator/live mode, and attach a reviewed **Save diagnostics** bundle. It contains logs, system versions, and connection settings, but no camera images.
