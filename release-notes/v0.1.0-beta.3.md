Beta 3 adds Italian alongside English.

### Italiano

- Selettore **English / Italiano** nella barra superiore, con scelta ricordata al riavvio.
- Interfaccia tradotta: schede comando, parametri, vista di volo, impostazioni, conferme ed errori.
- Numeri decimali con la virgola in italiano.
- Cambiare lingua mantiene schede, valori e avanzamento del programma. I file delle lezioni funzionano in entrambe le lingue.
- [Guida in italiano](https://fablab-bergamo.github.io/tello-flight/it/).

### English

- Switch interface language immediately using the top-bar selector. On first launch Italian systems use Italian; other systems use English.
- Override startup language with `--language it` or `--language en`.
- Flight controls, command cards, parameters, dialogs, confirmations and status messages are translated.
- Saved program identifiers, SDK commands and structured diagnostic events remain stable across languages.
- Localization tests cover card/parameter translations, dynamic messages, dialog buttons, persistent preferences and switching language during a run.
- Release CI renders both English and Italian card editors from the packaged application on Windows and Linux.

Extract the entire Windows ZIP or Linux tar.gz and keep the executable with `_internal`. Linux targets Ubuntu 24.04 x86-64. No separate Python installation is required.

The app starts in simulator mode. **Real-drone validation remains pending.**
